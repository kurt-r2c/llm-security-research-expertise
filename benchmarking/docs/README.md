# docs

Pre-registrations and results, in the order they were written. They are the record of what was
decided before the runs and what the runs showed; they were not rewritten after the fact except
where noted inside each file. Commands in them use the `ablate` CLI; the original layout was a
`eval/` directory inside a skills repository.

| File | What |
|---|---|
| `METHOD.md` | Arms, suites, scoring, statistics, run records |
| `RESULTS.md` | SSRF suite, vanilla vs a skill suite, with and without a verifier gate |
| `PREREG-wide.md`, `RESULTS-wide.md` | Injection, authorization and logic suite, plus authorizer mix-ups |
| `PREREG-settlement.md`, `RESULTS-settlement.md` | Skill invocation check, guides and forced skills, pairwise statistics, CVE suite |
| `RESULTS-facts.md` | Facts note on 17 post-cutoff CVEs. The pre-registered rule fails |
